Make sure all circuits are properly connected and grounded before starting.

First, connect your laptop to the same WiFi network you'll use for the ESP32 (any network with internet access works - no hotspot/local-IP setup needed anymore).
Second, open main.ino and check WIFI_SSID / WIFI_PASSWORD match that network. That is the only thing you should need to change. (MQTT now runs over the internet via the public HiveMQ broker, so no IP addresses need to be found or updated.)
Third, make any necessary changes to the sketch and upload it to the ESP32. If no changes were made, continue without uploading.
Fourth, launch Ollama.
Fifth, open CMD prompt in the digestomatic main folder and run python foria_bridge.py
  (This connects to your HiveMQ Cloud cluster over TLS - no separate Mosquitto step needed anymore.)
Sixth, launch the web dashboard and login with username Eudaimonia and password Digestomatic.
Seventh and final step, check that Foria is able to receive prompts, the measurement data is being sent and that motor stirs upon request.

Note: this uses your private HiveMQ Cloud cluster, so no one else can see or publish to these topics.
